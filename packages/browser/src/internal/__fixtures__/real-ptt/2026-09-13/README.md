## 格式與使用限制

每個 `.txt` 保留 terminal driver 當下 24 行（未補滿每行 80 欄）。第二次成功連線另有 `.ansi` 與 `.json`：前者由 terminal.js **重建** ANSI，後者保留游標與每行屬性，均不是原始 WebSocket bytes。純文字可用於 prompt/parser fixtures；JSON 適合檢查行屬性。不要將重建 ANSI 當成網路分包、時序或原始編碼測試輸入。

帳號（含大小寫變體）與 IPv4 已替換；替換可能改變字寬，JSON 屬性／游標仍來自原始座標，因此遮蔽區域不適合作精確游標斷言。公開文章作者及板主等 ID 保留。帳密不含在檔案內，未讀取私人信件。

部分 BBS 裝飾圖案經現有 Big5/terminal 處理後失真，保留現況以標示採集器限制。登入、主選單及登出美工圖不能當成正確解碼的 golden image。重複／未變的刷新也保留，不能由「送出按鍵」或某張舊畫面推定操作成功。

`main-menu-return` 與 `hot-boards-after-Ctrl-Z` 是當時操作意圖，實際只觀察到回到 Test 看板，**未取得熱門看板**。首次長正文在本機 PTY 輸入上限被阻擋，未送往 PTT；改成短批次後才實際輸入，因此正式事件只含成功交付給控制器的批次。另有兩次未取得畫面的連線嘗試，其現存診斷留在 `.cache/ptt-terminal-captures/session-tests/`，不納入成功 fixture。
