# Goal 11：長回文自動分段設計

狀態：依規則 0.3.0 實作；正式驗證結果見 implementation notes。取代先前五分鐘、三分鐘與群組標頭方案，沒有新增群組 ID。

## 接收與發送契約

- 非連續同作者同目標片段的時間上限為兩分鐘，包含邊界；連續片段不受時間差限制。作者、目標、控制事件與終止條件仍有效。
- 新版尾標為 `|` 續接與 `_` 終止；不提供舊版 `||`／`|!` 特殊語意。只移除最後一個單字元尾標。
- 短文也須終止：已有 `.。!?！？;；` 不再加記，否則补 `_`。長文最後片段遵守相同規則。
- 中間片段盡量占滿真實容量，僅在終止標點、字面尾標或欄寬邊界需要時補 `|`，不每行裝飾。
- 滿行直接串接，未滿行插入換行。主動換行落在滿行位置時使用 `|` 橋接；空白行也占一筆推文。
- 回覆他人時各段重複相同 `回N樓：`，全用原生 →。回覆文章首段沿用使用者方向，其他片段用 →。
- 編輯後內容保持不透明，不再解析其末尾符號；原始聚合結構不因編輯改變。

## 層級分工

core 提供可選 gateway 能力 `sendReplyDraft`、replyId 轉原始樓號與聚合。browser 擁有 UAO 編碼、容量、wire 規劃、終端工作流程與傳送紀錄。UI 提供完整草稿、進度與明確續送，不計算實體片段。

`sendReplyDraft({ operationId, article, content, pushType, replyId?, resume? }, onProgress?)` 回傳 `Result<ReplyDelivery>`。ReplyDelivery 包含 `operationId/status/confirmed/total`。舊單筆 API 不改義；未實作此能力的 gateway 不會將長文偷偷改走單筆送出。

## 容量與預驗證

實際容量受帳號欄寬與 IP 模式影響，不採固定 80 bytes。browser 輸入探測文字到確認畫面後只按 n 取消，絕不發送 y。確認同篇文章後，從 padded 文字欄寬扣除 NUL 保留位得到容量。依據 PTT 官方 `mbbsd/bbs.c` 的 recommend/getdata 呼叫。

每個字元使用傳輸相同的 UAO codec 計算並確認 encode/decode 往返。前綴與標記均計入容量；補記超限必須重新切段。整份計畫經真實核心聚合器預驗證，必須還原同一內文與目標，否則整批拒絕，不能先送一半才發現錯誤。

正文 CRLF 正規化、移除草稿外緣空白。片段首尾空白、控制語句等若无法透過既有規則保留，預驗證拒絕。正規化後草稿最多 500 全形單位（1,000 半形單位），依 UAO 編碼占用計數，含正文空白與換行，不含系統前綴與尾標。超限於發送前拒絕，不截斷草稿。字面尾標只移除最後一個，前面的符號保留。

## 傳送狀態

1. 先快照輸入及文章 key，operationId 綁定全文、文章、目標、方向、計畫與登入世代；不受外部物件後續修改影響。
2. 整批取得終端序列鎖；核對文章身分，能取得 AID 時使用 canonical AID。
3. 逐段輸入。每次確認 y 前核對帳號、容量與完整內容，若被截斷或變更則取消。
4. 沿用既有文章工作階段、確認／讀回證據，確定送達才增加 confirmed。
5. 明確 not-sent 為 paused；續送使用原 ID，從未確認片段開始。未知结果為 uncertain，不能盲目重試。
6. complete ID 再次呼叫不重送。跨登入／斷線世代、帳號變更、容量變更或修改草稿均不可接續舊計畫。
7. 進度 observer 的例外不影響傳送結果。

## 介面

輸入長文不再受單則 80-byte 限制；編輯控制命令仍走舊單則流程。送出後鎖定文字、方向與插入工具。只有 complete 才 refresh 後關閉；paused 保留草稿與繼續送出按鈕；uncertain 保留紀錄，重新整理不解鎖重送。

目前只保存於 Article 元件及 browser 記憶體，關閉／重開同一窗格可續送，離開文章、頁面重載不提供持久恢復，不自動續送。

## 限制與相容

- 尾部終止只隔開後方，無法阻止與既有未封口的前文聚合。
- 同帳號另一連線插話、控制事件可能打斷或污染聚合；多段不是原子交易。
- 中途停止時最後終止符可能尚未送達，部分內容不保證與後續獨立。
- 舊客戶端可能直接顯示新版符號。兩分鐘也會重新分組舊文章，故規則版本提升至 0.3.0。
- 無法保證任意草稿逐字往返；不能安全表示時送出前拒絕。
- 本階段使用 fixture、腳本終端與 fake gateway，不在真實 PTT 寫入。

## 測試

接收 fixtures 驗證新版符號與舊符號不再特殊解析、兩分鐘邊界、目標與控制隔離及編輯不透明性。browser 驗證實際 codec 容量、滿行、橋接、嵌套、取消探測、錯誤確認取消、不可變輸入、登入世代、部分續送與 uncertain 禁重送。fake gateway 經公開 core API 送出後讀回。UI 覆蓋長文、即時進度、關閉重開、完整成功才關閉與不可重送。
