# Goal 11 自動分段回文 Implementation Notes

## 決策

- 採舊聚合規則加 `|!`，不使用群組標頭；單段不加，允許與前文自然聚合。
- 核心默认非連續片段五分鐘；web profile 三分鐘；連續片段不受時間限制。
- 尚未確認的推文不得自動重送。保留已確認片段數與草稿，部分送達不視為完成。
- 真實容量不是固定 80。官方 `mbbsd/bbs.c` recommend 使用 maxlength 與含 NUL 的 getdata；確認畫面按 maxlength 補齊欄寬。取消的確認畫面作為目前終端的容量證據，避免猜測 IP 模式。
- 字元需通過 UAO encode/decode；不以非 ASCII 一律兩 bytes 取代實際編碼驗證。

## 限制

- 舊規則無法逐字保留任意尾空白及字面尾標。分段計畫先由真實聚合器還原驗證，不一致時不發送。
- 同帳號其他連線插話、跨客戶端未標記單段、控制事件仍可能影響聚合；不宣稱交易式原子性。
- 本階段不對真實 PTT 執行發文／推文測試。

## 驗證

實作完成後記錄命令與結果。
