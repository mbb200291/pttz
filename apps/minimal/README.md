# pttzzz / minimal

以文字為主的 PTT 唯讀介面。支援看板瀏覽、文章閱讀、嵌套討論與編輯歷史。

## 啟動

在專案根目錄執行：

```sh
npm ci
npm run build:packages
npm run dev:minimal:local   # 本機測試站
npm run dev:minimal:ptt     # 正式 PTT
```

開啟 http://localhost:5183/。頁首會顯示目前連線的站台；送出登入表單才建立連線，密碼不會儲存。

不登入也能試用：http://localhost:5183/?preview=1 使用離線示例資料。

## 閱讀

- 從熱門看板或直接輸入看板名稱進入；列表底部可載入更多文章。
- 從文章返回看板會保留已載入的列表與閱讀位置。
- 文章未完整載入時可按「重新載入文章」，重試期間保留已讀取內容。
- 正文保留空白、換行與作者設定的文字色彩；過寬內容可水平捲動，也可開啟自動折行。
- 回文依討論關係排列，評分採用整理後的推噓數。
- 回文與編輯歷史依畫面寬度自然換行，保留原有換行與空白；長網址也能折行。
- 撤回的回文保留位置，顯示「此回文已撤回」，其下討論仍可閱讀。
- 展開編輯紀錄可查看原始版本與每次修改後的完整內容。
- 已刪除的文章無法開啟。

本介面不提供發文、回覆、投票或編輯。連線結束後，按「重新登入」重新開始。

開發設定與驗證方式見 [開發指南](docs/development.md)。
