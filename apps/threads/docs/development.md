# 串流選文與更新

## 候選範圍

- 取得前五個熱門看板，名稱不分大小寫去重。
- 每板依序呼叫 `listArticles({board,limit:20})`，有 `nextCursor` 才讀第二頁；每次重新整理最多十次文章列表呼叫。
- 「兩頁」指 API 結果頁，每頁最多 20 筆，不是兩張終端畫面。gateway 的定位、游標驗證及 lookahead 可能需要額外終端讀取，因此不承諾固定秒數。
- 本機與正式站採相同選文規則，不再使用最低 20 分門檻或多次級距篩選。

## 日期

每次刷新開始時固定 `Asia/Taipei` 的今天與前兩個日曆日，不是精確的 72 小時。比對列表的月／日，支援跨年及閏日；明確的 `YYYY-MM-DD` 日期同時比對年份。沒有日期或無法辨識的日期不納入。

PTT 列表通常只有月／日，無法排除同月同日的往年文章。這是摘要來源的限制，不額外逐篇讀正文確認年份。若未來需要嚴格時間範圍，須由公開 API 提供可靠的完整發文日期。

固定示例的預覽模式略過日期限制，避免範例隨時間過期；仍排除置底、刪除文章並排序。介面標示示例而非即時熱門。

## 排序與截取

排除置底、作者為 `-` 的已刪除列及重複文章，再依原生推噓分由高到低排序，取前 30 篇。零分及負分不排除。相同分數保留取得順序（看板順序、頁內來源順序），不隨機洗牌。

有有限的 `nativeScore` 時使用該值；否則使用列表標籤：數字依值、空白為零、`爆` 為 100 以上級距、`X1` 至 `X9` 為負分十位級距、`XX` 為負 100 以下級距；未知標籤置後。級距只用於排序，不把它顯示成精確票數；無法區分兩篇「爆」文章的真實高低。

這是有限候選範圍的近三日精選，不是全站或完整三日排行榜。熱門板較早的高分文章可能不在兩頁內；沒有符合日期的文章時不偷偷放寬範圍。

## 更新與失敗

單一終端連線循序讀取，不平行切換看板。先完成候選蒐集、去重及排序，再整批替換畫面；讀取進度只更新狀態，不逐篇插入造成重排。正文仍按可視範圍逐步讀取。

第二頁失敗保留第一頁結果；單板失敗繼續其他看板。熱門來源或所有看板的第一頁都失敗時保留既有列表。成功但無符合條件文章則顯示空列表；離頁或斷線後不再開始後續頁面，也不採用遲到結果。

這些策略只屬於 Threads UI，不變更核心聚合規則、白皮書或其他介面的選文行為。
