# pttzzz Web 使用指南

pttzzz Web 讓你在瀏覽器裡閱讀 PTT，以討論串呈現分散的推文，並提供圖片、YouTube 預覽與鍵盤快捷操作。

## 瀏覽看板

在首頁輸入看板名稱，按 Enter 進入，也可以從最近瀏覽、我的最愛或熱門看板選擇。

看板內可搜尋文章標題或輸入 #AID 查找文章，也能設定推文數門檻。往下捲動會載入較舊的文章；重新整理可查看最新文章。

## 閱讀文章

文章會配合視窗寬度排版，並保留作者使用的文字顏色。若表格或文字圖案因換行而不易閱讀，點右側的「原始排版」可保留原有行寬與配色，左右捲動查看；再點一次恢復自動排版。

圖片與 YouTube 預覽會出現在正文的網址位置，影片點擊後播放。原始排版則保留網址，將預覽放在正文下方。

文章下方的來源註腳會顯示 PTT 發信站、完整文章網址與來源，點選網址可在新分頁開啟 PTT 網頁版。

## 討論與回覆

同一人的連續發言會依合併規則整理，回覆他人的留言則呈現在對應討論下方。討論最多縮排三層，較深的回覆會排列在第三層。

- 文章下方的推／噓數反映整理後的文章評分。
- 「回覆」計入所有顯示的留言，包括回覆別人的留言；不計單純評分與編輯、撤回指令。
- 討論串的「討論」數只計第一層，因此可能少於回覆總數。

你可以對文章或某則留言評分、加入討論，或使用「回覆此文」留言。要另發一篇回應文章，使用文章上方的「回應」。

## 發文與編輯

登入後，可在看板發文，或回應文章。編輯器提供文字高亮、粗體、八種文字顏色、清除格式與預覽；這些格式適用於文章，不適用於單行推文。

重新編輯既有文章時，原有顏色可能不會保留，送出前請先檢查預覽。

自己的留言可使用編輯或撤回功能。發文、回覆與編輯都需要在編輯器內確認送出。

## 鍵盤快捷鍵

在首頁、看板或文章按 H，可查看目前頁面的快捷鍵；按 Esc 或點視窗外關閉。輸入文字或已有對話框開啟時不會觸發。

### 首頁

| 按鍵 | 功能 |
| --- | --- |
| S | 跳到看板輸入框 |
| Enter（輸入框內） | 進入輸入的看板 |
| Esc（輸入框內） | 離開輸入框，保留文字 |

### 看板

| 按鍵 | 功能 |
| --- | --- |
| S 或 / | 跳到文章搜尋框 |
| Enter（搜尋框內） | 搜尋標題或查找 #AID |
| Esc（搜尋框內） | 離開搜尋框，保留文字 |
| Z | 設定推文數門檻 |
| Enter／Esc（門檻設定內） | 套用／取消 |
| Ctrl+P | 開啟發文編輯器 |
| ← | 返回首頁 |

### 文章

| 按鍵 | 功能 |
| --- | --- |
| X | 開啟推文／留言編輯器 |
| Y（或 R） | 開啟回應文章編輯器 |
| ← | 返回看板 |
| Esc（推文／留言編輯器內） | 關閉編輯器 |

快捷鍵可以直接使用，不必先選取卡片。輸入文字、選取文字、操作影音或開啟對話框時，頁面快捷鍵會暫停；發文與回覆仍需登入並具備相應權限。

方向鍵與 PageUp／PageDown、Home／End 保留一般捲動操作，表中列出的 ← 返回除外。Tab／Shift+Tab 不切換頁面元素；搜尋、發文與回覆可直接使用上表快捷鍵。格式工具、圖片與個別留言操作使用滑鼠或觸控。

Ctrl+Tab 等瀏覽器分頁快捷鍵不受影響。

字母快捷鍵不需搭配 Shift。Mac 的發文快捷鍵同樣是 Ctrl+P；Cmd+P 仍會開啟瀏覽器列印。

## 登出

首頁右上角的「登出」會結束這次網頁連線，不會登出你在其他 PTT 客戶端的連線。
